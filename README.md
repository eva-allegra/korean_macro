Korean Numpad Remap (Windows, AutoHotkey v2)

Was es macht
- Remappt nur den NUMPAD-Bereich 0-9.
- Die normalen Zahlentasten oben (1-0) bleiben unveraendert.
- Mehrfaches Tippen auf dieselbe Numpad-Taste innerhalb von 700 ms wechselt durch die Zeichen (wie bei alten Handy-Keypads).
- F12 schaltet den Mapper ein/aus.

Datei
- korean_numpad_3x4.ahk

Installation
1. AutoHotkey v2 installieren:
   https://www.autohotkey.com/
2. Die Datei korean_numpad_3x4.ahk doppelklicken.
3. In ein Textfeld klicken und mit dem Numpad testen.

Aktuelles Preset (physische Numpad-Position)
- 7 -> ㄱ, ㅋ
- 8 -> ㄴ, ㄹ
- 9 -> ㄷ, ㅌ
- 4 -> ㅂ, ㅍ
- 5 -> ㅅ, ㅎ
- 6 -> ㅈ, ㅊ
- 1 -> ㅇ, ㅁ
- 2 -> ㅣ
- 3 -> ㆍ
- 0 -> ㅡ

Layout anpassen
- In korean_numpad_3x4.ahk den Block keyMap aendern.
- Reihenfolge der Zeichen in einem Array bestimmt die Tap-Reihenfolge.

Hinweis
- Dieses Skript sendet direkt Hangul-Zeichen. Du brauchst dafuer nicht zwingend das Windows-Koreanisch-Layout aktivieren.
